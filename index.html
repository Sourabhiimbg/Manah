Connect Your Google Drive

Enter your Google Drive API credentials to start browsing your video library.

How to get credentials:
1. Go to console.cloud.google.com
2. Create a project → Enable Google Drive API
3. Create credentials → API Key (restrict to Drive API)
4. Share your Drive folder publicly (or with your domain)
5. Copy the Folder ID from the URL:
drive.google.com/drive/folders/[FOLDER-ID]
